# HEART: Emotionally Grounded Video Captioning via Hierarchical Emotion-Aligned Representation

This is the **official repository** of our paper:

**HEART: Emotionally Grounded Video Captioning via Hierarchical Emotion-Aligned Representation**

Published in *IEEE Transactions on Affective Computing (IEEE TAFFC), 2026*.

## Overview

Emotional Video Captioning (EVC) aims to generate video descriptions that are both factually accurate and emotionally expressive.

We propose **HEART**, a unified framework that jointly models hierarchical visual semantics and multi-scale temporal context for emotionally grounded video captioning. We also introduce **EmoStruct**, a benchmark dataset featuring fine-grained emotional annotations at both the subject and predicate levels.

## Dataset

We provide the **EmoStruct** dataset developed for emotionally grounded video captioning.

Please refer to the dataset directory for details about the dataset, annotations, and usage instructions.

**Current release:** This repository currently provides the dataset resources only. The source code for HEART, including training and inference implementations, will be released separately.
